# How Well can an Claude Opus 5.5 Imitate a 19th Century Human Author?

## AI Generations - 126 * 3 Generations
2,500 - 3,000 word excerpts generated by **Claude Opus 5.5**

**Across 3 Prompting Styles:**
_"Imitate the style of the author"_
1) **Zero Shot Prompting** - No examples were given as examples for Claude to model style off
2) **One Shot Prompting**- One excerpt were given as examples for Claude to model style off
3) **Multi Shot Prompting**- Three excerpts were given as examples for Claude to model style off

**3 Topics Per Prompting Style:**
_"Depict the following scene []"_
1) A tense conversation between a couple
2) Cousins catching up after a long time apart
3) A parent reprimanding a young child

### 14 authors * 3 prompting styles * 3 topics per prompting style = **126 TEXTS**

_**(Three Generations with the same prompts were taken to repeat the study for generalizability)**_
